# BPIC-17 — Assignment I

Process discovery, conformance checking and decision mining on the BPIC-17
loan application log, for *Business Process Prediction, Simulation and
Optimization* (TUM).

The model is built as a base model for simulation rather than as documentation,
which is why precision is prioritised over fitness and all work-item activities
are kept. The final model replays 80.7% of traces at a precision of 0.611. The
reasoning behind each step is in the accompanying report.

## Data

Not included (578 MB). Download `BPI Challenge 2017.xes.gz` from
[4TU.ResearchData](https://doi.org/10.4121/uuid:5f3067df-f10b-45da-b98b-86ae4c7a310b)
and put it in the project root. The first run parses it once and caches it as
`bpi_2017.parquet`; later runs load the cache.

## Setup

    conda env create -f environment.yml
    conda activate bpic17
    jupyter lab

Run `BPI Challenge Assignment 1.ipynb` top to bottom. Everything in `results/`
is regenerated by it.
